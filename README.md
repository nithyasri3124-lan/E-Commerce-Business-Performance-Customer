# E-Commerce Business Performance & Customer Analytics

## Project Overview

This project analyzes e-commerce business data to understand **sales, profit, customers, products, returns, and marketing performance**.

The project uses **Excel, SQL, Python, and Power BI** to clean, analyze, visualize, and present business data.

## Objectives

* Analyze sales and revenue performance
* Analyze profit and profit margin
* Understand customer purchasing behavior
* Analyze product performance
* Analyze returns
* Evaluate marketing campaign performance
* Create an interactive Power BI dashboard

## Tools Used

* **Excel** – Data cleaning and analysis
* **SQL / MySQL** – Data querying and analysis
* **Python** – Data analysis and visualization
* **Pandas & NumPy** – Data processing
* **Matplotlib** – Visualization
* **Power BI** – Interactive dashboard

## Dataset

The project includes the following datasets:

* Customers
* Products
